Evaluated
Quick Quantise on Play: not recommended
Scope is ambiguous on a multi-layer screen, strength needs a preview, it adds a control to the screen we keep simple, and it invites “fixing” takes mid-performance. Quantise stays two taps away: tap a layer → Quantise…, with preview, explicit scope and Undo. Revisit only if testing shows people hunt for it.
