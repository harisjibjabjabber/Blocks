# Bass expansion: portable implementation and evidence

11 November 2026. This implements the foundation and voice experiments from the [spike](bass-expansion-spike.md). Listening preference is still an open gate. These are original synthesis recipes, not artist presets or proprietary circuit emulations.

## Four source voices, one stable foundation

Rotor retains the earlier quadrature-table source. Growl, Throat and Fray use the same Spin/Motion/Grit controls and five waveform choices, with a separately rendered original fundamental and DC component. Their additional harmonics exclude harmonic one, so neither ratio modulation nor the formant weighting retunes the foundation.

- **Growl:** Fourier coefficients of integer-ratio phase modulation, combining carrier/ratio pairs 3:2 and 5:3. Grit changes modulation index; Motion sweeps two broad formant concentrations. This is evaluated as a bounded additive spectrum, not by naive full-band phase warping.
- **Throat:** narrower moving spectral resonances select a different upper-harmonic balance. These are Lorentzian weights in the generator, not a claimed vocal-tract circuit or resonant IIR filter.
- **Fray:** a ratio-modulated component plus signed harmonic clusters changes with the note's actual envelope and velocity. Motion varies cluster balance; the low foundation remains fixed. This is deterministic expression, without random pitch offsets.

The new recipes use harmonics 2–32 with a smooth pitch-dependent upper cutoff. Their finite harmonic ceiling makes very low notes darker than an unlimited source, particularly where a high formant would require more than 32 harmonics. It is an explicit sound/CPU choice, not an alias-free or universally richer-sound claim. Time-varying amplitudes can produce sidebands; the existing Spin guard is conservative rather than a mathematical guarantee for every modulation combination.

Original coefficients are generated by `tools/generate_bass_pm.py` from the Bessel series, with negative-frequency terms folded and DC/fundamental removed. See Julius O. Smith's primary exposition of [sinusoidal FM/PM sidebands](https://www.dsprelated.com/freebooks/mdft/Sinusoidal_Frequency_Modulation_FM.html). The synthesis combination is also consistent with the general FM/subtractive/additive architecture described in [Ableton's Operator manual](https://www.ableton.com/en/manual/live-instrument-reference/#operator); no code or proprietary recipe was copied.

Only active recipe coefficients are prepared, once per logical voice/oscillator sample; unison copies reuse them. Partial evaluation uses a sine/cosine recurrence. Changes between recipes crossfade. No render allocation, additional logical note voice or new source FIR latency is introduced. The native preview shares these exact functions, with explicit representative envelope/velocity inputs when no note is playing.

## Shared timing and Motion Curl

The additive version-2 Bass configuration is 80 bytes: version/reserved plus two 36-byte entries (`enabled`, `voice`, `synced`, `retrigger`, `spin_hz`, `motion`, `grit`, `cycle_beats`, `curl`). Only this current format is accepted; previous Bass formats and conversion APIs have been removed.

`cycle_beats` uses quarter-note beats, from 1/32 to 64 beats; the UI resolves notes, triplets, dotted values and bars into this duration. Free Spin remains 0.1–20 Hz. Synced rates are derived from BPM and duration and are not silently capped at 20 Hz. The separate 12-byte clock stores 40–240 BPM and meter 1–16. Clock state is required and drives Bass, LFO and Delay. Local note-sequencer BPM is preserved on import. A deliberate host Global BPM edit updates those saved sequencer settings.

Curl uses `expm1(-curl*phase)/expm1(-curl)` (identity at zero), bounded to ±0.8. It changes motion inside a cycle while preserving its endpoints and duration. Timing changes preserve phase. Optional retrigger follows valid final note attacks, including generated notes, once per sample; canceled attacks and panic cannot leave a pending reset. Native warped phase, raw phase and actual rate are available for truthful animated previews.

## One centred Sub

The additive 32-byte Sub state has Off by default, Sine/Triangle, octave −2/−1/0, Lowest/Last priority, Clean/FX routing and Level. It follows the final note stream after note processors, including repeated keys, MIDI channels, pedal ownership, restoration of previous held notes and release. It has one centred oscillator, independent of main polyphony and unison count. Its amp envelope is captured from the main amp settings; legato pitch transitions use the existing Glide controls. It does not inherit pitch drift or Pitch Drop.

Clean joins **after** the main nonlinear output stage and bypasses Tone, colour, Sauce, Width and Delay. Common master gain then applies; only the combined output is hard-clamped at ±1 for overload safety, so the existing final-sample meter sees clipping. There is no hidden level compensation. FX gets its own Tone/colour/rack chain and then the common Width/Delay/output stages. Clean is immediate; FX includes the chosen processors' latency. At octave zero, coherent main/Sub signals can reinforce or cancel; this is not concealed with a gain boost. Stop/panic clears Sub ownership and tails.

## Verification recorded for this slice

`bass_expansion_tests.cpp` passes ten focused WASM-O2 groups covering layouts/atomic current-format validation, timing and canceled retrigger, distinct source spectra, Sub ownership and centring, Clean/FX separation, live edits and exact block invariance without render allocations, actual logarithmic glide, generated Arp-note following, and modern Harmonics envelope-context integration. The five current Rotor groups cover source spectra and lifecycle, and 25 worklet bridge tests passed. Native CI remains a separate backend gate.

Measured examples:

- Four source previews: maximum complex fundamental error **4.60e−9**, raw peak **3.37**, with every pair measurably different. Fray envelope/velocity changes leave that fundamental unchanged.
- Actual Clean Sub glide waveform versus analytical log-frequency integration: maximum error **9.21e−8**.
- Clean Sub output is exactly identical with the main Tone/Drive/Fullness/Width/Delay set to extreme values versus neutral settings in the isolated fixture; switching to FX changes it, and panic silences both paths.
- All three Harmonics profiles receive amp-envelope times velocity for their detector only. Actual CAPI plucks show Dynamics attack/body contrast increases of **7.41 dB** at velocity 0.2 and **7.33 dB** at 0.8 in the stated test. This is a fixture result, not automatic loudness matching.

Six fixed-gain four-second WAVs are in `work/bass-expansion-evidence` beside the repository: Rotor, Growl, Throat, Fray, Fray+Clean Sub, Fray+FX Sub. Main gain is 0.3 and oscillator level 0.7, with the same notes/velocities and no per-file normalization. Initial peaks were respectively 0.1254, 0.0386, 0.0910, 0.1363, 0.1636 and 0.1559. Different peak/RMS levels are disclosed; musical preference needs listening, not just these numerical tests.

The CMake targets `blocks_synth_bass_expansion_tests` and `blocks_synth_bass_expansion_audition` reproduce the focused tests and clips. The audition executable takes an existing output directory. The public install/consumer and fail-fast core runner include the new headers and tests. This document makes no desktop deadline or phone CPU guarantee; the combined-chain benchmark is recorded separately.
